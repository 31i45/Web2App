## Skill 有效性验证

本套 skill 的价值已体现：
- 发现了 **cargo audit 从未执行**（供应链盲区）
- 发现了 **ADR 完全缺失**（决策遗忘风险）

如果不用这套 skill，这些问题会一直潜伏。skill 有效。

## 自我审计（执行 00）

- **[反证]** 我尝试反证「cargo audit 未执行是问题」：可能项目依赖少且都是知名 crate（wry/tao/png），CVE 风险低？→ 反证不成立：知名 crate 也会有 CVE（如 log4j），不扫描就是盲区。
- **[简化]** 改进项能否合并？→ P0 的 cargo-audit 和 ADR 不能合并，一个是 CI 一个是文档。P1 的文档校验和违禁词扫描可合并为一个 CI step。
- **[风险]** 1) 评分主观性：不同人评分可能差 ±1 → 缓解：评分基于可验证数据（unwrap 数、测试数），非纯主观。2) 改进项可能引入新问题 → 缓解：每个改进项单独评估。3) 审计本身可能遗漏 → 缓解：列出未覆盖项（性能基准、fuzz 测试）。
- **[验证]** 所有数据可由命令复现（见基础数据表）。
- **[来源]** 数据来自本地 `cargo test`、`cargo tree`、静态扫描，非编造。
